RLS Check

A quick security review of a Supabase project: row-level security, table grants, policies, SECURITY DEFINER functions and storage buckets, explained in plain English with the SQL to fix each problem.

Private by design: the query only reads your database's settings (never your data), and the report is made in this browser tab. Nothing is sent anywhere.
